Vector Field & Curve Explorer

Follow a point along a curve and compare the vector field with the curve’s unit tangent and unit normal. Move the arc-length slider or play the motion.

Mathematical setup

r(t) = (x(t), y(t))
a ≤ t ≤ b
F(x,y) = (P(x,y), Q(x,y))
R(s) = r(t(s)),   0 ≤ s ≤ L
T(s) = R′(s)
N(s) = (T₂(s), −T₁(s))
fwork(s) = F(R(s)) · T(s)
fflux(s) = F(R(s)) · N(s)
W(s) = ∫₀ˢ fwork(u) du
Φ(s) = ∫₀ˢ fflux(u) du

Define the mathematics

Enter expressions using JavaScript-style math notation. Supported examples include sin(t), pi, t^2, and exp(-x^2-y^2). Click Apply to rebuild the curve and field.
